## 1. Ardha Performance Data Flow Diagram

```
[ ARDHA WORKSTATION STATE ]
  │ (Spot, Gap, PCR, Walls, Bias, Regime)

  │ 1. Emits ArdhaEvaluationRecord (Phase: PRE_MARKET / LIVE_INTRADAY / POST_MARKET)

  ▼
[ ATOMIC DISK PERSISTENCE ]
  │ File Path: /opt/ardhamind/staging/data/performance_records/YYYY-MM-DD.json
  ▼
[ PREDICTION REALITY EVALUATOR ] (src/analytics_engine/prediction_reality_evaluator.py)
  │ Evaluates Actual Outcome vs Ardha Prediction (50-Field Standard Contract)
  ▼
[ SERVER BRIDGE API ] (src/server_bridge.py -> get_performance_records)
  │ JSON Serialization over stdio / RPC
  ▼
[ ARDHA PERFORMANCE UI ] (src/frontend/components/settings/ArdhaPerformancePanel.tsx)
  └── Displays Hit/Miss Metrics, Accuracy Score, Confidence Calibration
```

## 2. ArdhaEvaluationRecord Schema & Field Inventory

| FIELD | TYPE | DESCRIPTION | IMMUTABILITY RULE |
| :--- | :--- | :--- | :--- |
| `id` | `UUID` | Unique evaluation record identifier | Immutable |
| `trading_date` | `String (YYYY-MM-DD)` | Associated trading session date | Immutable |
| `metric_id` | `String` | Metric identifier from 50-Field Contract (e.g. `M01_EXPECTED_OPEN`) | Immutable |
| `metric` | `String` | Human-readable metric title | Immutable |
| `category` | `String` | Metric domain (`OPENING_GAP`, `SPOT_LEVEL`, `DIRECTIONAL_BIAS`, `VOLATILITY`, `OPTIONS`) | Immutable |
| `phase` | `Enum` | Evaluation phase (`PRE_MARKET_PLAN`, `LIVE_INTRADAY`, `POST_MARKET_CLOSE`) | Immutable |
| `ardha_value` | `String / Number` | Exact prediction value generated by Ardha | **STRICTLY IMMUTABLE** |
| `actual_value` | `String / Number` | Ground truth value observed from market | Updated upon market settlement |
| `prediction_at` | `ISO Timestamp` | Exact time prediction was recorded | **STRICTLY IMMUTABLE** |
| `evaluated_at` | `ISO Timestamp` | Exact time outcome evaluation occurred | Updated upon evaluation |
| `status` | `Enum` | Evaluation result (`HIT`, `MISS`, `PARTIAL`, `PENDING_SETTLEMENT`) | Updated upon evaluation |
| `error_margin` | `Float` | Numerical delta between predicted and actual | Updated upon evaluation |
| `confidence` | `Float` | Model confidence score (0.0 to 1.0) | Immutable |

## 3. Performance Storage Files & Schema Attributes

- **Storage Location**: `/opt/ardhamind/staging/data/performance_records/YYYY-MM-DD.json`
- **File Format**: JSON Array of `ArdhaEvaluationRecord` objects.
- **Write Mechanism**: Atomic temporary file write (`.tmp`) followed by atomic rename (`os.replace`).
- **Immutability Enforcement**: `PerformanceTrackerEngine.save_records()` raises `ValueError("Immutability Violation: Cannot mutate original prediction fields")` if an attempt is made to overwrite `ardha_value`, `prediction_at`, `metric`, or `phase` of an existing record.
- **Retention Policy**: Permanent historical archive per trading date.
