# Phase 1 UI Specification

## Navigation

The sidebar contains exactly six entries, in the order defined by the product specification. NIFTY Live and Settings are always accessible; restricted workspaces explain what input is missing.

## Top bar

The top bar contains only product identity, IST clock with market status, Kite connection, market-feed status, notifications and Settings. Portfolio value, P&L, user identity, mode selection and detailed diagnostics are excluded.

## Workspace composition

- **NIFTY Live:** Overview, Price & Trend, Options
- **Pre-Market Planner:** Evening Outlook, 8:50 AM Briefing, Opening Checklist
- **Today’s Analysis:** current-session meaning, contributions, option changes and scenario outcomes
- **NEWS & UPDATES:** Live Feed, Market Impact, Events, Corporate, Watchlist
- **Live Assistant:** current scenario, confirmations, missing confirmations, invalidation, changes and next watch
- **Settings:** Kite, OpenAI, Data Sources, Notifications, Diagnostics, Appearance, About

Existing visual language and responsive behavior are retained.
